# Analisis Customer Churn Telco

Proyek ini menganalisis data customer churn dari penyedia layanan telekomunikasi untuk mengidentifikasi pola perilaku pelanggan yang berpotensi berhenti berlangganan (churn).

## Hasil Analisis & Visualisasi
Semua grafik visualisasi dan draf memo insight otomatis disimpan di dalam folder `output/`:
1. **Churn Rate per Tipe Kontrak (`1_churn_by_contract.png`)**
2. **Churn Rate per Kelompok Tenure (`2_churn_by_tenure.png`)**
3. **Churn Rate per Metode Pembayaran (`3_churn_by_payment.png`)**
4. **Distribusi Biaya Bulanan (`4_monthly_charges_distribution.png`)**

## Temuan Utama
- Pelanggan dengan kontrak bulanan (Month-to-month) memiliki churn rate tertinggi (42.7%).
- Periode kritis retensi berada pada 6 bulan pertama pelanggan mulai berlangganan.
- Pengguna metode pembayaran Electronic Check berasosiasi kuat dengan angka churn yang tinggi.
